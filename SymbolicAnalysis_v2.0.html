3b) Auto-C

The automatic C range is estimated with the main 1D profile over x = RRn. Its default short->long candidate threshold is 14%. A second profile with a fixed 45% threshold validates branch strength. Only the main profile supplies c_lo/c_hi, and operational C exists only when both profiles are robust. The symbolic C classification still uses near-identity and u = (x+y)/2; c_hi marks the beginning of the right cap, not its strict geometric end.
